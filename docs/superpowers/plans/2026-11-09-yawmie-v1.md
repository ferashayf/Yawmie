# Yawmie v1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Yawmie v1 from one codebase in two forms: the website app on the iPhone Home Screen (data in IndexedDB) and a single-file Claude artifact (data in Claude `db`), both starting empty, matching `design/demo.html`.

**Architecture:** Pure logic in `src/logic/` (tested first), data behind a `StorageAdapter` with an IndexedDB and an Artifact adapter, one build-time `mode` with a `features` object that screens read. Preact screens ported from the demo. Two Vite builds: `dist/` (PWA, GitHub Pages) and `dist-artifact/index.html` (one file).

**Tech Stack:** Vite, TypeScript, Preact (`@preact/preset-vite`), `vite-plugin-pwa`, `idb-keyval`, `vite-plugin-singlefile`, Vitest.

**Spec:** [PRD.md](../../../PRD.md), [ARCHITECTURE.md](../../../ARCHITECTURE.md), [CLAUDE.md](../../../CLAUDE.md); look and copy: [design/demo.html](../../../design/demo.html) (version 62).

## Global Constraints

- No backend, accounts, analytics or third-party calls at runtime. Artifact mode talks only to Claude `db`, `user`, `downloads`.
- No sample data in the app. `emptyState()` = default areas + categories only. Made-up data only in tests and the demo.
- Arabic (RTL) + English; Western digits 0-9 everywhere (`Intl` with `-u-nu-latn`); week starts Sunday; Gregorian only.
- Money = integer halalas; shown `SAR 1,250.00`. Dates = local `YYYY-MM-DD` / `HH:mm`, never UTC.
- `src/logic/` is pure: no browser APIs, no UI imports. Logic functions take `today` / `now` as parameters.
- Only `src/storage/` touches IndexedDB or `window.claude`. Screens read `features`, never `mode`.
- Never mutate stored state; build a new state and `save()` it.
- All UI text in `src/i18n/ar.ts` + `en.ts`, same keys. Copy strings from the demo's tables (`design/demo.html` lines 816–1050).
- Logical CSS only (`inline-start`/`inline-end`); `<bdi>` around money and mixed text; text inputs `dir="auto"`.
- Buttons and Return call actions directly; never rely on form `submit` alone.
- Design tokens, corner scale, type ramp, icons: CLAUDE.md → Design. Drawn SVG icons only, no emoji or typed characters in buttons.
- Commits: `<type>: <description>`; author email = the owner's GitHub `noreply` address. Never commit `.env`, backups, exports, `.privacy-words`.
- **Ask the owner first** before: creating the GitHub repo, the first public push, DNS for yawmie.me, publishing any artifact, installing tools on the Mac outside the project.
- After every task: `npm test` green, a browser check in Arabic + English × light + dark, then tell the owner in plain words what works and what doesn't.

## Review Focus

1. **Midnight while the app is open** — Today, Plan, overdue and Safe to spend must switch to the new day without a reload. Owned by Task 20; test `today rolls over at midnight`.
2. **Emoji or two-part characters at an artifact piece boundary** — a lone half-character can be mangled by the server. Owned by Task 18; test `never splits a surrogate pair`.
3. **The artifact open on phone and Mac at once** — saves must never mix pieces from two saves. Owned by Task 18; test `interleaved saves leave one complete copy`.
4. **A bad, huge or newer-version backup file** — import must refuse with a clear reason, never half-replace data. Owned by Task 15; tests `rejects newer schemaVersion`, `rejects over 5 MB`, `rejects negative amount without refund flag`.
5. **Safe to spend at month edges and with no budget** — last day, first day, over budget, no budget. Owned by Task 11; tests listed there.
